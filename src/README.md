# Christian Megachurch Roleplay Game

## Scripts

### Server Scripts
- `ServerScriptService/ChurchManager.server.lua`: Manages the church facilities and events.
- `ServerScriptService/EventManager.server.lua`: Handles church events and announcements.

### Client Scripts
- `StarterPlayerScripts/PlayerController.client.lua`: Controls player interactions and movements.
- `StarterPlayerScripts/UIManager.client.lua`: Manages the user interface for the game.

### Modules
- `ReplicatedStorage/ChurchData.module.lua`: Stores data about the church facilities and events.
- `ReplicatedStorage/PlayerData.module.lua`: Stores data about the players.

## Assets

### Church Assets
- `ReplicatedStorage/ChurchModels`: Contains the 3D models of the church facilities.
- `ReplicatedStorage/ChurchTextures`: Contains the textures for the church facilities.

### Environment Assets
- `ReplicatedStorage/EnvironmentModels`: Contains the 3D models of the natural forest environment.
- `ReplicatedStorage/EnvironmentTextures`: Contains the textures for the natural forest environment.

## How to Use
1. Place the server scripts in the `ServerScriptService` folder.
2. Place the client scripts in the `StarterPlayerScripts` folder.
3. Place the modules in the `ReplicatedStorage` folder.
4. Place the church assets in the `ReplicatedStorage/ChurchModels` and `ReplicatedStorage/ChurchTextures` folders.
5. Place the environment assets in the `ReplicatedStorage/EnvironmentModels` and `ReplicatedStorage/EnvironmentTextures` folders.

## Notes
- Ensure all scripts and modules are properly linked and referenced in the game.
- Test the game thoroughly to ensure all interactions and events work as expected.
