# Glass Haven Church

Glass Haven Church is a high-quality, realistic, modern Christian megachurch roleplay game designed for Roblox Studio. It features a stunning contemporary glass megachurch with a beautiful architectural design, enormous floor-to-ceiling glass windows, realistic reflective glass panels, a tall modern entrance, a large welcoming lobby, elegant walkways, wide properly constructed stairs, accessible ramps, functional double glass doors, a massive sanctuary with rows of realistic seating, a beautiful elevated stage, a central pulpit, a large cross, modern screens, professional stage lighting, warm ceiling lights, decorative interior lighting, realistic materials, detailed walls, ceilings, floors, columns, hallways, classrooms, offices, restrooms, a prayer room, a baptism area, and other believable church facilities. The church is surrounded by a beautiful natural forest environment with varied realistic trees, bushes, flowers, rocks, terrain elevation, grass, pathways, landscaped gardens, parking spaces, sidewalks, streetlights, outdoor benches, and carefully placed decorative objects. The game includes a complete, functional, multiplayer Christian church roleplay system with an organized user interface, a main menu, a church directory, a calendar of events, a prayer request board, a donation system, a member management system, and a communication system.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Click on "File" in the top menu and select "Open Model".
4. Navigate to the downloaded project files and select the main file.
5. Click on "Open" to import the project into Roblox Studio.

## Use

1. Place the server scripts in the `ServerScriptService` folder.
2. Place the client scripts in the `StarterPlayerScripts` folder.
3. Place the modules in the `ReplicatedStorage` folder.
4. Place the church assets in the `ReplicatedStorage/ChurchModels` and `ReplicatedStorage/ChurchTextures` folders.
5. Place the environment assets in the `ReplicatedStorage/EnvironmentModels` and `ReplicatedStorage/EnvironmentTextures` folders.
6. Test the game thoroughly to ensure all interactions and events work as expected.
